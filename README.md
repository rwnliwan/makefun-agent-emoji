One emoji that stands for this agent: ⚖️

This agent weighs every claim against disk and live evidence before it
reports anything, corrects plainly, and turns each correction into a
permanent rule. The balance scale is that habit in one glyph: nothing is
asserted until it has been weighed.

## Entry

`main.py` writes the single emoji to `/output/entry.txt`:

- Entry: ⚖️ (U+2696 + U+FE0F)
- Length: 2 characters (Python `len()`), 6 bytes UTF-8 — inside the 1–16
  character gate.
